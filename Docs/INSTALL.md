## Automated Build Scripts

The repository includes pre-configured automation scripts located in the [`Scripts/`](../Scripts/) directory. Both scripts automatically compile in Release mode, package the distribution format, and reveal the output in Finder when complete.

### 1. macOS Build & DMG Installer (`Scripts/build-macOS.sh`)

The macOS build script compiles the native AppKit application, embeds high-resolution depth icons, applies ad-hoc signing, and packages a styled DMG disk image.

To run:
```bash
./Scripts/build-macOS.sh
```

**Features of the DMG Installer:**
- **Custom Visual Styling**: Sleek dark gradient backdrop with Apple design tokens.
- **SF Symbols**: Dynamic system iconography with neon directional lighting.
- **Directional Arrow & Pedestals**: Visual guide directing the user to drag the app into the `/Applications` folder shortcut.
- **Automatic Finder Reveal**: Mounts and reveals the generated `build/Artifacts/Remote-Desktop-macOS.dmg` upon completion.

### 2. iOS Build & IPA Package (`Scripts/build-iOS.sh`)

The iOS build script compiles the universal iPhone/iPad SwiftUI target with the ReplayKit Broadcast Extension, compiles the asset catalog, and packages an unsigned `.ipa` archive ready for sideloading.

To run:
```bash
./Scripts/build-iOS.sh
```

**Output:**
- Generates `build/Artifacts/Remote-Desktop-iOS.ipa`.
- Automatically opens and reveals the `.ipa` in Finder for immediate access.

## macOS Installation & Setup

### Installing from DMG

1. Run `./Scripts/build-macOS.sh` or double-click `Remote-Desktop-macOS.dmg`.
2. In the opened DMG window:
   - Drag the **Remote Desktop** application icon onto the **Applications** folder shortcut.
3. Once copied, eject the DMG image.
4. Launch **Remote Desktop** from `/Applications` or Spotlight (`Cmd + Space`).

### Required macOS Permissions

Remote Desktop requires the following system permissions to operate as a host or viewer:

1. **Screen Recording** (`ScreenCaptureKit`):
   - Prompted on first session or enable in:
     `System Settings > Privacy & Security > Screen Recording` -> Enable **Remote Desktop**.
2. **Accessibility** (`CGEvent` remote keyboard & mouse control):
   - Required to inject mouse movements, clicks, and keyboard strokes.
   - Enable in: `System Settings > Privacy & Security > Accessibility` -> Enable **Remote Desktop**.
3. **Local Network** (`Bonjour` peer discovery):
   - Required to discover and connect with nearby devices over Wi-Fi/LAN without configuration.
   - Enable in: `System Settings > Privacy & Security > Local Network`.

## iOS Installation & Sideloading

Because iOS does not allow direct installation of `.app` files from Safari without signing, the unsigned `.ipa` generated by `build-iOS.sh` can be sideloaded using any standard tool:

### Method 1: Sideloadly (Recommended)

1. Download and open [Sideloadly](https://sideloadly.io/) on your Mac.
2. Connect your iPhone or iPad via USB or ensure it is reachable on the local Wi-Fi network.
3. Drag `build/Artifacts/Remote-Desktop-iOS.ipa` into Sideloadly.
4. Enter your Apple ID and click **Start**.
5. Once installed, trust your developer certificate on your device under:
   `Settings > General > VPN & Device Management`.

### Method 2: AltStore / TrollStore / SideStore

1. Send `Remote-Desktop-iOS.ipa` to your iOS device via AirDrop, iCloud Drive, or local file sharing.
2. Open the file in **AltStore** or **TrollStore** and tap **Install**.

### Method 3: Xcode Devices & Simulators

1. Connect your device to your Mac and open Xcode.
2. In the Xcode menu bar, select `Window > Devices and Simulators` (`Cmd + Shift + 2`).
3. Select your device from the left sidebar.
4. Drag `build/Artifacts/Remote-Desktop-iOS.ipa` into the **Installed Apps** section.

### Required iOS Permissions

1. **Local Network**:
   - Tap **Allow** when prompted on first launch to allow Bonjour discovery of host Macs.
2. **Screen Broadcast**:
   - To stream your iOS screen to a Mac, swipe into Control Center, long-press **Screen Recording**, and select **Remote Desktop**.

## Application Icons & Visual Assets

The repository contains customized application icons designed around Apple's SF Symbols and modern design aesthetics:

- **iOS Variant**:
  - Full-bleed square canvas with modern midnight-slate background.
  - Luminous dual-display SF Symbol (`display.2`) with subtle depth backlight.
  - Sized for all iPhone and iPad SpringBoard resolutions.
- **macOS Variant**:
  - Standard macOS continuous squircle tile (824x824) on a transparent canvas.
  - Multi-tier physical drop shadows (ambient, directional, contact).
  - Subtle 3D chamfer / inner highlight rim on the squircle boundary.
  - Elevated SF Symbol with cast drop shadows.
  - Compiled into `Sources/macOS/Resources/AppIcon.icns`.

To regenerate the assets at any time, run:
```bash
swift ./Scripts/generate-assets.swift
```
